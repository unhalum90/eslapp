Product Requirements Document: The ESL ArchitectProject Goal: To build a "Magic School" equivalent tailored for the French National Education system, enabling ESL teachers to transform existing PDFs, collaborate with a chat-driven creation engine, and manage a free-form pedagogical workspace.1. Executive SummaryThe ESL Architect is a specialized "Workspace as a Service" for French secondary school teachers. It solves the "blank page" problem and the "analog-to-digital" friction by allowing teachers to ingest old PDF resources, manipulate them via AI within a free-form editor, and export them as classroom-ready worksheets aligned with CECRL (Common European Framework of Reference for Languages) standards.2. Target User & ContextUser: French Public School ESL Teachers (Collège/Lycée).Context: High classroom heterogeneity (A1 to B2 levels in the same grade), strict adherence to official "Programmes," and a heavy reliance on printed (analog) worksheets.3. Core Functional PillarsA. Intelligence Ingestion (OCR & Extraction)PDF Upload: Support for multi-page PDFs (scans, textbook pages, news articles).Structured Extraction: Utilize Layout-Aware OCR (e.g., Mistral OCR or Document AI) to preserve reading order, tables, and image placements.Markdown Conversion: Convert extracted content into clean Markdown to serve as the "ground truth" for the AI engine.B. The Free-Form Workspace (The "Canvas")Hybrid Editor: A Tiptap-based rich-text editor that supports standard manual editing alongside AI-driven block generation.State Management: Sync editor state to Supabase jsonb columns in real-time.Student/Teacher Toggles: A feature allowing teachers to mark text (e.g., bolding specific words) and instantly convert the document into a "Gap-Fill" version for students.C. The Chat-Based Creation EngineContextual Awareness: The chat engine has full read/write access to the "Canvas" state.Agentic Actions:Rewrite: "Level down this text from B1 to A2."Expand: "Generate 5 'True/False/Justify' questions based on the selected text."Scaffold: "Create a vocabulary 'Word Box' with French translations for difficult terms."System Constraints: Enforced pedagogical standards (CECRL levels, French grading rubrics).D. Export & LogisticsPDF Generation: High-fidelity PDF export using React-PDF.Version Control: Save "Snapshots" of worksheets to Supabase for reuse in future academic years.4. Technical Architecture (Antigravity Stack)ComponentSpecificationFrontendNext.js (App Router), Tailwind CSS, Lucide IconsEditorTiptap (ProseMirror) for the free-form canvasBackendSupabase (Auth, PostgreSQL, pgvector for RAG)AI OrchestrationGoogle 3 Preview (via API) for superior pedagogical reasoningDocument ProcessingMarker or Mistral OCR for PDF-to-MarkdownFile StorageSupabase Storage (for original PDFs and extracted assets)5. User JourneyIngest: Teacher uploads a 3-page PDF of a London travel guide.Analyze: The system extracts the text and displays it in the Center Canvas.Collaborate: Teacher types in the Right Chat: "This is too hard for my 6ème. Simplify the text and add a section on 'giving directions'."Edit: The AI rewrites the text in the Canvas. The teacher manually moves a paragraph and adds a personal note in the Free-form Section.Finalize: Teacher clicks "Generate Student Version." The system hides the answer key and creates blanks for the vocabulary.Export: Downloads a branded, formatted A4 PDF ready for the photocopier.6. Success MetricsTime Savings: Reduction in worksheet preparation time from 60 mins to <10 mins.Accuracy: LLM adherence to CECRL level constraints (checked via teacher feedback).Engagement: Number of documents generated and saved per month.7. Future Roadmap (v2)YouTube Integration: Ingest transcripts and generate listening comprehension guides.Department Sharing: Shared folders in Supabase for school-wide resource libraries.Image Generation: Automatic flashcard generation using Imagen 4.0.
